# Thinking Tools — Навигатор техник мышления

Скилл для Claude Code, который помогает решать задачи с помощью 25 проверенных техник мышления из [untools.co](https://untools.co/).

## Что это

AI-фасилитатор, который:
- Общается по-человечески, без формальностей
- Проактивно предлагает чем может помочь
- Подбирает подходящую технику под ситуацию
- Проводит через технику пошагово
- Подводит итоги и формулирует следующие шаги

## Какие техники внутри

### Принятие решений (10 техник)
| Техника | Для чего |
|---------|----------|
| **Шесть шляп мышления** | Посмотреть на решение с 6 разных перспектив |
| **Матрица Эйзенхауэра** | Приоритизировать задачи по важности и срочности |
| **Мышление второго порядка** | Продумать долгосрочные последствия решения |
| **Матрица решений** | Объективно сравнить несколько вариантов по критериям |
| **Матрица воздействия и усилий** | Приоритизировать по соотношению эффект/усилия |
| **Лестница умозаключений** | Проверить не делаешь ли выводы на пустом месте |
| **Модель сложного выбора** | Понять какой тип решения перед тобой |
| **Цикл OODA** | Быстро принимать решения в условиях неопределённости |
| **Фреймворк Кеневин** | Определить тип ситуации и выбрать правильный подход |
| **Уверенность: скорость vs. качество** | Решить делать быстро или качественно |

### Решение проблем (8 техник)
| Техника | Для чего |
|---------|----------|
| **Диаграмма Исикавы (Рыбья кость)** | Найти корневые причины проблемы |
| **Лестница абстракции** | Переформулировать проблему на другом уровне |
| **Диаграмма разрешения конфликтов** | Найти win-win решение в конфликте |
| **Ящик Цвикки** | Генерировать нестандартные решения через комбинации |
| **Модель продуктивного мышления** | Структурированный путь от проблемы к решению |
| **Инверсия** | Найти решение через анализ "а что если сделать наоборот" |
| **Деревья проблем** | Разбить сложную проблему на управляемые части |
| **Первые принципы** | Разложить до основ и собрать заново |

### Системное мышление (5 техник)
| Техника | Для чего |
|---------|----------|
| **Модель айсберга** | Докопаться до глубинных причин через 4 уровня |
| **Круги связей** | Увидеть взаимосвязи и петли обратной связи |
| **Карта концепций** | Визуализировать отношения между элементами системы |
| **Балансирующая обратная связь** | Понять механизмы стабилизации системы |
| **Усиливающая обратная связь** | Понять эффект снежного кома (рост или падение) |

### Коммуникация (2 техники)
| Техника | Для чего |
|---------|----------|
| **Ситуация-Поведение-Влияние (SBI)** | Дать обратную связь без осуждения |
| **Пирамида Минто** | Структурировать подачу информации — вывод в начало |

## Как использовать

1. Добавь папку `thinking_tools` в свой проект или в `~/.claude/skills/`
2. Claude Code автоматически подхватит SKILL.md
3. Просто опиши свою ситуацию — AI предложит подходящую технику и проведёт через неё

## Примеры запросов

- "Не могу выбрать между двумя офферами"
- "В команде конфликт, не можем договориться об архитектуре"
- "Куча задач, не знаю за что хвататься"
- "Нужно написать письмо руководству с предложением"
- "Проект постоянно буксует и я не понимаю почему"
- "Хочу запустить продукт но не уверен стоит ли делать MVP или сразу нормально"

## Источник

Все техники основаны на библиотеке [untools.co](https://untools.co/) — коллекции инструментов мышления для принятия решений, решения проблем и системного мышления.
